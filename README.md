# Claude Skill Kit

ชุดสกิล Claude Code 8 ตัวที่ช่วยให้สั่งงานครั้งเดียวแล้วได้งานที่ตรงใจ ไม่ต้องไล่แก้ทีละรอบ ติดตั้งแล้วรัน `/make-it-mine` หนึ่งครั้ง มันจะปรับทุกอย่างให้เข้ากับคุณ

## แต่ละสกิลคืออะไร

| สกิล | ใช้ทำอะไร | ทำงานเมื่อไร |
|---|---|---|
| `make-it-mine` | ปรับทั้งชุดให้เป็นของคุณ (ภาษา แผน รสนิยม กฎการเทสต์) และให้เคล็ดลับเขียนพรอมต์ | พิมพ์ `/make-it-mine` เอง (รันครั้งแรก และรันซ้ำเมื่ออยากปรับ) |
| `work-mode` | โหมดทำงานยาว: สรุปเป้าหมายเป็น 4 บรรทัด แล้วลงมือจนเสร็จ พร้อมหลักฐาน | พิมพ์ `/work-mode` เอง |
| `idea-interview` | คุยไอเดียแบบ co-founder: ซักถาม แย้ง เสนอทางที่กล้ากว่า ก่อนลงมือ | อัตโนมัติเมื่อคุณมีไอเดีย หรือพิมพ์ `/idea-interview` |
| `unslop` | ตรวจหน้าจอ แอนิเมชัน และคำที่ดู "เครื่องทำ" หรือเลอะเทอะ แล้วแก้ก่อนส่งงาน | อัตโนมัติก่อนส่งงานที่คนจะดู หรือพิมพ์ `/unslop` |
| `motion` | ออกแบบแอนิเมชัน UI ที่ดูประณีต: จังหวะ easing การเปลี่ยนสถานะ | อัตโนมัติเมื่อทำอะไรที่เปิด ปิด หรือขยับ |
| `modern-web` | เลือกใช้ฟีเจอร์เบราว์เซอร์สมัยใหม่แทนไลบรารีหรือแพตเทิร์นเก่า | อัตโนมัติเมื่อเขียน UI, CSS, ฟอร์ม |
| `last30days` | หาว่าคนจริงพูดอะไรเกี่ยวกับแอปหรือเครื่องมือใน 30 วันล่าสุด พร้อมลิงก์ | อัตโนมัติเมื่อถามว่า "คนว่ายังไงกับ X" |
| `be-ambitious` | ยกงานให้ได้ผลลัพธ์ที่คุณจะชอบ ไม่ใช่แค่ขั้นต่ำที่พิมพ์ โดยไม่เปลืองโทเคน | พิมพ์ `/be-ambitious` เอง |

## ติดตั้ง

สกิลคือโฟลเดอร์ที่มีไฟล์ `SKILL.md` ก็แค่คัดลอกโฟลเดอร์ทั้ง 8 ไปไว้ใน `~/.claude/skills/`

Windows (PowerShell) รันในโฟลเดอร์ของชุดนี้:

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.claude\skills" | Out-Null
Get-ChildItem -Directory | Where-Object { Test-Path "$($_.FullName)\SKILL.md" } | ForEach-Object { Copy-Item $_.FullName "$env:USERPROFILE\.claude\skills\" -Recurse -Force }
```

macOS / Linux:

```bash
mkdir -p ~/.claude/skills
for d in */; do [ -f "$d/SKILL.md" ] && cp -R "$d" ~/.claude/skills/; done
```

จากนั้นเปิด Claude Code ใหม่ (หรือเริ่มเซสชันใหม่) เพื่อให้เห็นสกิล

## ครั้งแรก: รัน /make-it-mine

พิมพ์ `/make-it-mine` มันจะ:

1. ขออนุญาตก่อน แล้วอ่านเฉพาะข้อความที่คุณพิมพ์เอง ประมาณ 50 พรอมต์ล่าสุดจากเครื่องคุณ (ไม่อ่านคำตอบของ Claude ไม่เก็บ ไม่ส่งไปไหน) ถ้าไม่อยากให้อ่านก็ตอบข้ามได้
2. บอกสไตล์การสั่งงานของคุณ: ภาษา ความยาว การบอกว่า "เสร็จเมื่อไร" การแก้กลางทาง และงานที่สั่งบ่อย
3. ถาม 5 ถึง 8 คำถามสั้น ๆ: โปรเจกต์ สแตก ภาษาที่ให้ตอบ แผนที่ใช้ รสนิยมดีไซน์ ให้ถามก่อนหรือให้ตัดสินใจเอง และการเทสต์
4. แก้สกิลใน `~/.claude/skills/` ให้เข้ากับคุณ โดยสำรองไฟล์เดิมเป็น `.bak` และแสดง before/after สั้น ๆ ทุกไฟล์
5. ให้เคล็ดลับเขียนพรอมต์ 2 ถึง 3 ข้อ จากสิ่งที่เห็นในพรอมต์จริงของคุณ

อยากปรับใหม่เมื่อไรก็รันซ้ำได้

## ลอง 5 นาที

1. พิมพ์ `/work-mode` ตามด้วยพรอมต์ยาวหนึ่งอัน เช่น:
   ```
   /work-mode
   ทำหน้าเว็บ to-do list ง่าย ๆ ใน React
   Done when: เพิ่ม ลบ ติ๊กเสร็จได้ และรีเฟรชแล้วข้อมูลไม่หาย; เทสต์ผ่าน
   Not allowed: ห้ามเพิ่มไลบรารีนอกจาก React และ Vite
   Proof: โชว์ผลเทสต์และบอกวิธีเปิดดู
   ```
   ดูว่ามันสรุปเป้าหมายเป็นการ์ด 4 บรรทัด แล้วทำไปจนจบโดยไม่ต้องถามทีละก้าว
2. พิมพ์ `/idea-interview` ตามด้วยไอเดียสักอย่าง เช่น "อยากทำแอปจดค่าใช้จ่ายกับเพื่อนร่วมห้อง" แล้วลองตอบโต้ ให้มันแย้งและเสนอทางที่กล้ากว่า

## เขียนพรอมต์ครั้งเดียวให้ได้งานดี

ใส่ 4 อย่าง:

- **Goal**: อยากให้อะไรเป็นจริงเมื่องานจบ
- **Done when**: เช็กอะไรแล้วรู้ว่าผ่านหรือไม่ผ่าน (ต้องตรวจได้)
- **Not allowed**: อะไรที่ห้ามแตะหรือห้ามทำ
- **Proof**: อยากเห็นหลักฐานแบบไหน (ผลเทสต์ สกรีนช็อต)

ตัวอย่าง:

```
Goal: เพิ่มปุ่มโหมดมืดในหน้าตั้งค่า
Done when: กดแล้วสีทั้งหน้าเปลี่ยน รีเฟรชแล้วจำค่าไว้ และเทสต์เดิมยังผ่านหมด
Not allowed: ห้ามแก้หน้าอื่น ห้ามเพิ่มไลบรารี
Proof: โชว์ผลเทสต์ กับสกรีนช็อตสองโหมด
```

## เคล็ดลับประหยัดโทเคน (แผน Pro)

- ใช้ Sonnet ที่ effort ต่ำถึงกลางเป็นค่าเริ่มต้น เก็บ Opus ไว้เฉพาะงานดีไซน์หรือคิดยากจริง ๆ
- หนึ่งเซสชันต่อหนึ่งงาน พอยาวมากให้เริ่มเซสชันใหม่ แล้วสรุปสั้น ๆ ไปต่อ
- บอกไฟล์ที่ต้องอ่านและไฟล์ที่แก้ได้ในพรอมต์ จะได้ไม่เสียโทเคนไปกวาดอ่านทั้งโปรเจกต์
